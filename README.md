# AbortController

A React + TypeScript project demonstrating how to properly cancel API requests using AbortController to prevent memory leaks and unnecessary network calls.

## 🛠 Tech Stack

- React 18
- TypeScript
- Vite
- Fetch API with AbortController

## 📝 Related Article

This project accompanies my dev.to article:  
**[Handling HTTP Requests in React with AbortController](https://dev.to/davidecannerozzi/handling-http-requests-in-react-with-abortcontroller-53jn)**
